중복 미디어 탐색

Jellyfin에 등록된 영상의 파일명과 상위 폴더에서 고유코드를 추출하여 중복 후보를 표시합니다. 검사는 파일을 변경하지 않습니다. 각 그룹에서 보존할 파일을 선택하면 나머지를 별도의 확인 절차 후 영구 삭제할 수 있습니다.

영구 삭제는 휴지통을 거치지 않으며 NAS에서도 복구할 수 없을 수 있습니다. 크기 기준 버튼은 선택 보조일 뿐 자동 삭제하지 않습니다.

일괄 보존 규칙

아래 규칙은 현재 표시된 각 그룹에서 보존할 파일만 선택합니다. 즉시 삭제되지 않으며, 선택 결과를 검토한 뒤 별도로 영구 삭제해야 합니다.

보존 파일을 선택한 그룹이 없습니다.
